# Граф зависимостей пакетов Cargo

## Общее описание
Консольная программа строит граф зависимостей пакета Rust (Cargo).
Настройки читаются из файла YAML. Зависимости берутся напрямую из
индекса crates.io без менеджеров пакетов.

## Описание настроек
Файл `config.yaml`:

| Параметр | Описание |
|----------|----------|
| package | имя анализируемого пакета |
| repository | адрес индекса или путь к тестовому файлу |
| test_mode | true: тестовый репозиторий из файла, false: интернет |
| output_file | имя файла с картинкой графа (.png) |
| max_depth | максимальная глубина анализа (целое число от 0) |
| filter | пакеты с этой подстрокой в имени не учитываются |

## Сборка и запуск тестов
```
pip install -r requirements.txt
./run.sh --config config.yaml
pytest
```

## Пример использования
```
./run.sh --config config.yaml
```
Программа выводит параметры в виде `ключ: значение`.


## Получение зависимостей (этап 2)
Данные берутся из индекса crates.io: для пакета скачивается файл
`https://index.crates.io/<путь>/<имя>`, где каждая строка JSON описывает
одну версию. Выбирается последняя версия без отзыва и без пре-релиза.
Учитываются только обычные обязательные зависимости (без dev, build и
опциональных).


## Построение графа (этап 3)
Граф строится рекурсивным обходом в глубину. Глубина ограничивается
параметром `max_depth`, пакеты с подстрокой `filter` пропускаются,
циклические зависимости обрабатываются без бесконечной рекурсии.

### Тестовый режим
При `test_mode: true` параметр `repository` указывает на файл вида:
```
A: B C
B: C
C:
```
Слева пакет, справа его прямые зависимости. Имена пакетов — большие
латинские буквы.


## Обратные зависимости (этап 4)
Режим `--reverse ИМЯ` выводит пакеты, которые зависят от заданного
пакета (прямо или через цепочку). Поиск идёт внутри графа,
построенного от пакета `package`, так как индекс crates.io не хранит
сведений о том, кто использует пакет. Используется тот же обход в
глубину, что и при построении графа, но на графе с развёрнутыми
рёбрами.

Пример:
```
./run.sh --config examples/config_test.yaml --reverse C
```
