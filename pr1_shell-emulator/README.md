# Эмулятор командной строки UNIX (вариант 19)

## Общее описание

Графическое приложение на Python (tkinter), которое имитирует работу
в командной строке UNIX-подобной ОС. Заголовок окна строится по реальным
данным ОС: `Эмулятор - [пользователь@компьютер]`.

Структура репозитория:

- `src/` — исходный код
- `tests/` — автоматические тесты (unittest)
- `scripts/` — скрипты для проверки работы эмулятора
- `run.sh` — запуск эмулятора и тестов

## Сборка, запуск и тесты

    ./run.sh          # запуск эмулятора
    ./run.sh test     # запуск всех тестов

## Этап 1. REPL

Ввод делится на команду и аргументы по пробелам.

- `ls [аргументы]` - заглушка: выводит своё имя и аргументы
- `cd [аргументы]` - заглушка: выводит своё имя и аргументы
- `exit` - закрывает эмулятор




## Этап 2. Конфигурация

Параметры командной строки:

 - `--vfs ПУТЬ` - путь к физическому расположению VFS (ZIP-архив)
 - `--script ПУТЬ` - путь к стартовому скрипту

При запуске все параметры выводятся в окно и в терминал.

Стартовый скрипт — текстовый файл, одна команда в строке. Пустые строки
и строки, начинающиеся с `#`, пропускаются. Команды выполняются по
очереди, на экране видны и ввод, и вывод. Строка с ошибкой пропускается:
выводится сообщение, выполнение продолжается.

Скрипты проверки параметров:

    ./scripts/params_basic.sh    # без параметров и по одному
    ./scripts/params_full.sh     # оба параметра вместе
    ./scripts/params_errors.sh   # ошибки в параметрах



## Этап 3. VFS

VFS загружается из ZIP-архива целиком в память: архив не распаковывается
и не изменяется. Двоичные файлы хранятся в памяти как байты, при выводе
показываются в base64. Если `--vfs` не указан или архив не читается,
используется пустая VFS. Приглашение показывает текущую папку VFS.

`vfs-info` - имя VFS и SHA-256 хеш данных архива

Тестовые архивы создаются скриптом (архивов в репозитории нет):

    python3 scripts/make_vfs.py   # создаёт build/vfs/*.zip

Запуск с разными VFS:

    ./scripts/vfs_minimal.sh   # один файл
    ./scripts/vfs_multi.sh     # несколько файлов
    ./scripts/vfs_deep.sh      # 3+ уровня папок и двоичный файл
    ./scripts/vfs_errors.sh    # архива нет / файл не ZIP
